# License Header Adder 
Questa skill garantisce che tutti i nuovi file sorgente abbiano l' intestazione di copyright corretta . 

## Istruzioni 
1 . **Leggi il modello**: Leggi il contenuto di `resources/HEADER.txt`.   
2 . **Applica al file**: Quando crei un nuovo file, anteponi esattamente questo contenuto.  
3 . **Adatta la sintassi**: - Per i linguaggi in stile C (Java, TS), mantieni il blocco `/* */` . - Per Python/Shell, converti in commenti `#` .
